Clock ​

Clock is a mutable temporal reference that follows wall-clock time or progresses at a configurable speed. It supports temporal windows, playback bounds, looping, and notifications. Time is calculated on demand; a timer is created only when needed for event observers.

js
import { Clock } from '@kalisio/common-time'

Constructor ​

Signature ​

js
new Clock(config, initialTime)

Description ​

Creates a running clock. In realtime mode, it follows system time and ignores initialTime. In simulated mode, it starts at initialTime and progresses using a monotonic reference. A non-unit speed selects simulated mode automatically unless mode is explicitly specified.

Parameters ​

NameTypeRequiredDescription
configobjectnoClock configuration, default {}.
initialTimeDateTime | Date | number | string | objectnoSimulated starting instant, default current time.

Configuration ​

PropertyTypeDefaultDescription
modestring'realtime''realtime' or 'simulated'.
timezonestring'UTC'IANA timezone for parsing and representing instants.
speednumber1Finite nonzero multiplier; negative values reverse simulated time. Realtime requires 1.
tickIntervalnumber1000Integer from 0 to 2147483647 in real milliseconds. Zero disables the periodic timer.
windowobject | nullnull{ start, end } offsets relative to the current instant, as ISO duration strings or Duration instances.
boundsobject | nullnull{ start, end } instants restricting playback.
loopbooleanfalseWrap at bounds rather than end; requires nonempty bounds.

window uses time-based ISO 8601 durations, such as -PT3H and PT0S. Calendar offsets (P1D, P1M, etc.) are not supported. Offsets must be ordered. The bounds range is half-open, [start, end). With looping disabled, reaching end or crossing below start ends playback and leaves the clock at the corresponding bound.

Throws ​

TypeError for invalid option shapes or types; RangeError for invalid modes, speed, timezone, window, bounds, or starting time.

Examples ​

js
const realtime = new Clock({ timezone: 'Europe/Paris' })

const playback = new Clock({
  mode: 'simulated',
  speed: 60,
  window: { start: '-PT3H', end: 'PT0S' },
  bounds: {
    start: '2026-11-20T09:00:00Z',
    end: '2026-11-20T15:00:00Z'
  },
  loop: true
}, '2026-11-20T12:00:00Z')

const range = playback.range() // TimeRange for the rolling three-hour window

objectClock configuration.

state ​

Signature ​

js
clock.state()

Description ​

Returns a frozen snapshot. The snapshot and its DateTime / TimeRange values are immutable; the clock itself is mutable.

Returns ​

PropertyTypeDescription
timeDateTimeCurrent instant.
rangeTimeRange | nullResolved temporal window, or null when no window is set.
statusstring'running', 'paused', or 'ended'.

Examples ​

js
const { time, range, status } = playback.state()
range.duration.toISOString() // 'PT3H'

range ​

Signature ​

js
clock.range()

Description ​

Resolves the configured window offsets against the current instant. range is a TimeRange, not a tick period; it is null when window is not configured.

Returns ​

TypeDescription
TimeRange | nullCurrent resolved time range.

Examples ​

js
const clock = new Clock({
  mode: 'simulated',
  window: { start: '-PT3H', end: 'PT0S' }
}, '2026-11-20T12:00:00Z')

clock.range().toString()
// '2026-11-20T09:00:00.000Z/2026-11-20T12:00:00.000Z'
clock.dispose()

configure ​

Signature ​

js
clock.configure(changes)

Description ​

Validates and applies partial configuration changes without replacing the instance. undefined values leave options unchanged; window: null or bounds: null clear those options. Validation failure keeps the previous configuration. A valid reconfiguration of an ended clock preserves its ended status. A successful change emits change, and may emit end if new bounds are reached.

Parameters ​

NameTypeRequiredDescription
changesobjectyesPartial configuration using constructor options.

Returns ​

TypeDescription
ClockCurrent instance.

Examples ​

js
playback.configure({ speed: -2 })
playback.configure({ window: { start: '-PT1H', end: 'PT0S' } })
playback.configure({ window: null })

set ​

Signature ​

js
clock.set(value)

Description ​

Sets the clock instant. Realtime clocks become simulated. Running/paused status is preserved; setting an ended clock makes it paused. An out-of-bounds instant is rejected when loop is false, or wrapped when loop is true. Emits change on success.

Parameters ​

NameTypeRequiredDescription
valueDateTime | Date | number | string | objectyesNew instant.

Returns ​

TypeDescription
ClockCurrent instance.

Examples ​

js
realtime.set('2026-11-20T12:00:00Z')
realtime.config().mode // 'simulated'

pause ​

Signature ​

js
clock.pause()

Description ​

Stops progression at the current instant. A successful transition emits pause, then change; it has no effect if already paused or ended.

Returns ​

TypeDescription
ClockCurrent instance.

resume ​

Signature ​

js
clock.resume()

Description ​

Resumes a paused clock. An ended clock must first be moved using set() or reset(). A successful transition emits resume, then change. A realtime clock returns to wall-clock time when resumed. If that puts it outside its non-looping bounds, it emits end.

Returns ​

TypeDescription
ClockCurrent instance.

Examples ​

js
playback.pause()
playback.resume()

reset ​

Signature ​

js
clock.reset()

Description ​

Restores a running realtime clock at the current system time, with speed: 1, bounds: null, and loop: false. Preserves the configured timezone, tick interval, and temporal window. Emits reset, then change.

Returns ​

TypeDescription
ClockCurrent instance.

Examples ​

js
playback.reset()
playback.config().mode // 'realtime'

Events ​

Signatures ​

js
clock.on(event, callback)
clock.once(event, callback)
clock.off(event, callback)

Description ​

Callbacks receive the event payload directly. on() subscribes, once() subscribes for one notification, and off() removes one matching subscription. on() and once() return unsubscribe functions.

EventPayloadDescription
tick{ time, range }Periodic notification while running.
change{ time, range, status }Explicit clock modification.
pause{ time, range, status }Paused.
resume{ time, range, status }Resumed.
reset{ time, range, status }Reset to realtime.
end{ time, range, status }Reached a playback bound and stopped.
loop{ time, cycles, direction }Crossed playback bounds; cycles is positive and direction is 1 or -1.

time is a DateTime; range is a TimeRange or null. Periodic timers run only while the clock is running, tickInterval > 0, and at least one tick, loop, or end observer exists. tickInterval is measured in real milliseconds, regardless of simulation speed. Other changes are still computed on demand.

Parameters ​

NameTypeRequiredDescription
eventstring | symbolyesEvent name. Built-in clock events use the strings listed above.
callbackfunctionyesReceives the corresponding payload.

Returns ​

MethodTypeDescription
on, oncefunctionUnsubscribe function.
offundefinedRemoves the first matching subscription.

Examples ​

js
const clock = new Clock({ window: { start: '-PT3H', end: 'PT0S' } })

const unsubscribe = clock.on('tick', ({ time, range }) => {
  console.log(time.toISOString(), range.toString())
})

unsubscribe()
clock.dispose()
