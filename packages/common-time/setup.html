setup ​

Configures the shared clock used by common-time. The application owns the clock's creation and lifecycle.

Signature ​

js
setup(options = {})

Parameters ​

OptionTypeRequiredDescription
clockClocknoActive clock to install as the shared clock.

setup() installs the clock when provided. Omitting clock or passing undefined leaves the current clock unchanged. A disposed clock raises an Error. Outside production mode, invalid options raise an AssertionError.

Returns ​

TypeDescription
undefinedNo return value.

Example ​

js
import { setup } from '@kalisio/common-time/setup'
import { Clock, getCurrentClock } from '@kalisio/common-time'

const clock = new Clock({ timezone: 'Europe/Paris' })
setup({ clock })
