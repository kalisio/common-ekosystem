common-core ​

Core utilities for the Kalisio ekosystem

Overview ​

common-core is a lightweight library that provides core utilities that work in both browsers and Node.js.

It is organized around 3 modules:

  • predicates — minimalist conditional and assertion functions
  • utilities — general purpose utility functions
  • operators — higher-order functions that process data

Installation ​

Install with your preferred package manager:

bash
pnpm add @kalisio/common-core
bash
npm install @kalisio/common-core
bash
yarn add @kalisio/common-core

Or use it directly from a CDN:

html
<script type="module">
  import { url } from 'https://unpkg.com/@kalisio/common-core/dist/index.mjs'
</script>
