# convert


## convertFromSexagesimal

### Signature
```javascript
convertFromSexagesimal(deg, min, sec, dir)
```

### Description

Converts Degrees, Minutes, Seconds to Decimal Degrees

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| deg | number | yes | degrees |
| min | number | no | minutes |
| sec | number | no | seconds |
| dir | &#x27;N&#x27; | no | optional direction |

### Returns

| Type | Description |
|------|-------------|
| number | decimal degrees, positive for N/E, negative for S/W |
